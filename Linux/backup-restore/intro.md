# Linux Backup and Restore Troubleshooting

In this scenario, you will set up the required directories and sample data, troubleshoot a failed backup script, and restore data from a backup archive.

You will:
1. Create the `/backup`, `/original`, and `/restore` directories
2. Add sample files to `/original/` to back up
3. Run the backup script to create an archive
4. Troubleshoot and fix any backup failures
5. Restore the backup to verify it works
