# Linux Backup and Restore Troubleshooting

In this scenario, you will troubleshoot a failed backup script using tar or rsync, identify configuration issues, and successfully restore data from a backup.

You’ll use the following commands:
- `ls -la /backup/`
- `cat /usr/local/bin/backup.sh`
- `tar -tzf /backup/backup.tar.gz`
- `rsync -av /source/ /destination/`
- `crontab -l`
